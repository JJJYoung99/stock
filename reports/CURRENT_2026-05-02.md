## 데이터 출처와 한계 (먼저 읽을 것)

* **`data/sample/*.csv` 는 합성 데이터**. `scripts/gen_sample_data.py` 가 `numpy.random` (seed=7) 으로 생성한 가짜 가격·이벤트. 종목 코드만 실재(005930, AAPL 등)하고 그 외 모든 숫자는 framework 동작 검증용으로 만든 것.
* **이 보고서의 카탈리스트는 모두 실재 사건**. 2026-04-29 ~ 2026-05-01 사이 공개 보도된 어닝/애널리스트 액션을 웹 검색으로 수집했고, 출처는 각 항목 아래 링크.
* **Posterior P(profit) 와 VaR 는 비어있음**. 실데이터용 historical EventStore (2-3년치 과거 이벤트) 가 아직 repo 에 없어서, 사후확률은 prior 로만 떨어져 의미 없는 0.5 로 나옴. `rule_score` 는 `configs/event_rules.yaml` 가중치로 계산했기 때문에 의미 있음.

## Framework 가 지금 시점에 줄 수 있는 답 vs 줄 수 없는 답

**줄 수 있는 답**

* 위 표의 `rule_score` — 이벤트 가중치에 magnitude 를 곱한, **방향성과 크기**를 나타내는 정규화된 신호.
* 가중치의 출처가 `configs/event_rules.yaml` 한 파일이라 audit 가능하고 본인 백테스트로 캘리브레이션 가능.

**줄 수 없는 답 (지금 단계에서)**

* `P(profit)`: 같은 타입 + 같은 magnitude 밴드의 과거 사례 분포가 필요. 실데이터용 historical EventStore 를 아직 만들지 않았기 때문에, 모든 사후확률이 prior(2,2) → 0.5 로만 나옴. → **2-3년치 DART/SEC 공시 + 가격 데이터를 한 번 ingest 하면 그때부터 실제 P(profit) 산출 가능.**
* `VaR / CVaR`: 위와 같은 이유. analog 분포에 의존.
* 종목·매크로 상관: 매크로 풀백/금리 변화 같은 컨텍스트 변수는 현재 점수에 반영 안 됨. ML 보강 단계에서 도입.

## 본 보고서를 framework 로 점수화해보고 싶다면

`data/real/us_events_2026-05-01.csv` 에 magnitude 가 측정 가능한 미국 이벤트 4건만 정리해뒀어. 다음으로 점수 확인:

```bash
catalyst events   --market sample-us --events data/real/us_events_2026-05-01.csv
catalyst score    --market sample-us --events data/real/us_events_2026-05-01.csv \
                  --ticker TWLO --date 2026-04-30
```

> Sample adapter 의 가격 데이터가 합성이라, 진짜 P(profit)·VaR 를 보려면 `pip install -e .[us]` 후 `--market us` 로 yfinance 를 붙여야 함. 그래도 historical event DB 가 비어있으면 여전히 prior-dominated.

## 다음 액션 (우선순위)

1. **실데이터 historical EventStore 1회 빌드.** OpenDartReader (KR) 와 sec-edgar-downloader/finnhub (US) 로 2023-01-01 ~ 오늘까지의 이벤트를 한 번 수집해 `data/real/{kr,us}_events.csv` 에 적재. 그 순간부터 framework 가 진짜 사후확률을 낸다.
2. **컨센서스 데이터 소스 결정.** 위 표의 빈칸들(직전 목표가, 컨센서스 EPS) 을 자동으로 채울 곳을 정하기 — 네이버 증권 컨센서스 페이지 / 한경 컨센서스 (KR), finnhub `earnings_calendar` (US) 가 무료 옵션.
3. **백테스트로 가중치 캘리브레이션.** `configs/event_rules.yaml` 의 weight 들은 보수적인 시작점. 1년치 실데이터로 백테스트 돌려 hit rate / Sharpe 가 가장 높은 가중치로 조정.
4. **최소 1주는 paper trade.** 자동매매 단계로 가기 전, 매일 아침 `catalyst score` 결과를 일지에 적고 실거래는 본인이 결정. 신호와 실현 수익률의 disagreement 를 모니터링.
